# 0.2.0 数值验证说明

验证工具链为 moonc 0.10.18+6c83a7f62。Windows 本地 wasm-gc、wasm、JS 分别通过严格 check/build、29 个测试及三个示例；native 的 check 通过，但本地缺少 MSVC 和 Windows SDK，构建未能运行，native 构建和执行应以该版本实际 Linux CI 为证据。

复现独立参考：

```sh
python -m pip install numpy==2.3.4 scipy==1.16.3
python scripts/reference_check.py --target wasm-gc
```

目标可替换为 wasm、js 或具备工具链的 native。每次输出 54 条记录，共 110,707 次标量比较；固定输入和阈值均在脚本中，测试数量不等于标量比较数量。

新旋转验证包含四组 64 阶方向编码旋转（含 beta=pi、负角、近零角），通过 SciPy 的独立三维向量旋转和球谐值生成预期系数；三组一般场旋转覆盖 21 个求值方向（含极点及近极点），同时比较逐带能量和最高阶的稠密 Padé 指数结果。生产实现采用分步 Taylor 作用，参考采用 SciPy 的稠密 expm，避免仅用同一实现的往返作为正确性证据。

转换验证分别构造两组不同的输入系数，对全部 18 种组合独立计算导入和导出预期值；单元测试另外以带内标签核验排列和相位，在 64 阶做全部组合往返，检查溢出、非法输入和防御复制。

本地 wasm-gc 实测最大绝对误差：

| 比较项目 | 最大绝对误差 |
|---|---|
| 64 阶基与 SciPy | 4.39e-15 |
| 球面采样分析与独立求积 | 9.11e-15 |
| 64 阶旋转方向编码 | 2.79e-14 |
| 一般旋转场与逆向三维点求值 | 1.06e-15 |
| 64 阶旋转系数与稠密 Padé 指数 | 1.39e-16 |
| 转换导出单向参考 | 3.47e-18 |
| 转换导入单向参考 | 1.12e-16 |

这些是给定输入上的测量值，并非所有输入的误差上界。极大角度的浮点约化、极端系数尺度及病态拟合仍需由调用方结合收敛和错误返回处理。
