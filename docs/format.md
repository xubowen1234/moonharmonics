# 系数交换格式 v1

JSON 根对象必须恰有 `format`、`convention`、`degree`、`coefficients` 四个字段。重复键、额外键、缺失键、非数值数组成员、分数阶数、非有限数值、形状不匹配均被拒绝。字符串输入限 2,000,000 个 UTF-16 单元，嵌套深度限 8。

```json
{"format":"moonharmonics-real-v1","convention":"orthonormal-cs-l*l+l+m","degree":0,"coefficients":[3.5449077018110318]}
```

该对象约表示常数 1。`degree` 为包含的最大 l，0..64；数组长度必须为 `(degree+1)^2`。索引为 `l*l+l+m`。正阶余弦、负阶正弦、CS 相位；这不是任意 ambisonic 或地学格式。双精度十进制序列化保留可往返值。

SN3D 互操作函数使用相同打包顺序及不含 CS 相位的半归一基：`S_lm=(-1)^|m|*sqrt(4*pi/(2*l+1))*R_lm`。故 SN3D 展开系数乘这个因子才得到本库展开系数。对基函数数值的转换方向相反。不得在基值与系数之间混用同一因子。

不接受自动推断归一化、未知版本或截断数组。版本 1 是本项目可交换格式，不声称属于既有标准协议。
